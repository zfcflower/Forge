# 07 工作台界面

本文件说明 FORGE 的桌面外壳、停靠布局、项目树、各面板、会话转录与输入框、命令面板、通知、设置、外观与本地化。

## 7.1 窗口外壳

- `WindowDecorations="BorderOnly"` + 扩展客户区：保留系统可缩放边框、去掉系统标题栏，客户区铺到窗口上边缘；标题行自绘，40 px，底色与 panel 标题栏同色。
- 标题行左侧：18×18 Forge 图标（`Assets/forge.png`／`forge-dark.png` 是同一图形的亮、暗两色，随主题换 `Image.Source`，所以与字标同色）、“● 扩展宿主”读数（绿=运行 / 黄=启动中 / 红=失败 / 灰=其余，tooltip 给状态、进程 id、失败原因；它报的是后台的宿主，所以紧贴在入口之前而不进右侧那簇图标按钮）、“自动化任务”入口（闪电 + 文字，徽标只计执行中与等待中的运行，0 时隐藏）——它是标题行里的 `Button.flat`：常态透明无边框，悬停才铺 `SurfaceHoverBrush`、按下 `IconButtonHoverBrush`（26 px 高，与旁边的图标按钮同高）；右侧：放大镜（命令面板）、重载提示词、计划、终端图标、设置，然后一条 1 px 间隔竖线（高 15 px＝13 px 窗口图形上下各高出 1 px，颜色同区域分隔线 `BorderBrush`），最后是最小化、最大化、关闭。
- 窗口标题仍是 Forge（任务栏与辅助功能识别）；所有窗口共用应用图标；主窗口启动居中于所在屏幕 `WorkingArea`，按桌面缩放换算尺寸并计入原生边框，可用区域过小时降低最小尺寸；用户后续移动/缩放不再重新居中。
- 标题行可拖动、双击最大化；按在按钮/输入框上不拖动；`CaptionPress` 是主窗口与浮出窗口共用的一份规则。
- 单实例：打开 `forge.db` 之前取数据根上的独占锁，拿不到只显示“Forge 已在运行。”后退出（不转交、不唤醒已有窗口）。

## 7.2 停靠布局

- 三个区域按**角色**命名而不按位置：**项目区**、**主区**、**检视区**；默认顺序 项目 | 主 | 检视，可拖拽互换（内容跟着角色走）。
- 项目区：上下叠放「项目」与「常规对话」两块 panel，中间 1 px 线可拖，比例存 `WorkbenchLayout.ProjectSplitRatio`（默认 0.5，任一侧不低于最小高度）。
- 主区：主选项卡组（只放会话标签）+ 底部组（子 Agent 选项卡组；终端也是这里的标签）；底部组标题栏右端的“SubAgents 历史 (n)”13 px——子 Agent 会话没有「已结束」状态，被再次领任务时会先回到活标签，这份菜单就是子会话的历史；点开的菜单一行一个历史会话（单行截断 + 全文 tooltip + 悬停底色，**行按钮横向铺满菜单宽**，所以短任务右侧的空白同样高亮、同样可点），行文本是「名称 · 任务摘要」——名称沿用标签规则（活子代理是发号器 id，如 `Worker-3`，历史行因此与刚关掉的活标签同名可对上；存储恢复行只剩种类）；菜单从新往旧排；行首圆点：本会话曾是活标签的行一律蒂芙尼蓝（盖过结局色，结局词留在 tooltip），存储恢复的行按结局着色（完成绿 / 失败红 / 停止橙 / 未知灰），不写状态文字。
- 检视区：上为文件 panel，下为 TODO | 评审 | 规格树 | 问题 选项卡组；两块之间的 1 px 线可拖，高度按 panel id 存快照的 `belowHeights`（缺省按已拖过者均值，全无则平分）；分配与夹紧由纯函数 `PanelStackSolver` 完成。
- 宽度：项目/检视最小 200 px、主区最小 360 px；首次默认 项目 336 / 检视 336 / 预览列 420。拖分隔条时另一侧吸收全部增量；被挤压的一侧主区先缩到最小，再按离分隔条由近到远缩其余区域；边栏缩到最小后继续拖，越过最小宽度一半（`CollapseOvershoot` = 0.5）才自动隐藏；主区永不隐藏。计算由 `RegionWidthSolver` 完成（拖动路径不分配，松手才写快照）。
- Panel 标题栏 28 px：单块标题与选项卡标签同一号字（正文档 13 px），标题 Bold、标签 Normal，层级只由字重表达；字重只取 400/700（中文侧没有 600 字体面）。图标尺寸不随字号变（标题栏工具仍 14 px）。
- 按钮按能力显示：自动隐藏/停靠（图钉实心=已停靠、空心=已隐藏）、缩小/还原（有可接收空间的同伴时可见；缩小只留 28 px 标题栏，正文隐藏但不销毁；同伴消失时自动还原）、新窗口/停靠（只给可浮出的对象）；除预览组外不放关闭按钮。没有“放大”按钮：局部放大用缩小同伴或把标签浮出。
- 子 Agent 标签**在排队或运行中不提供关闭**：关闭箱隐藏、右键菜单不给「关闭标签」、「关闭其他标签」跳过它，其他关闭路径（中键等）静默拒绝——标签是这轮运行的唯一窗口——流式增量与终局事件按 id 落进它，用户的停止与追问也都从这里。用户主动停止或运行结束后关闭箱回来，关闭即收进历史菜单；浮出不受限。
- 子 Agent 标签：顶部面包屑行右侧承载运行状态（圆点 + 状态词 + 单行备注、运行中的「停止」按钮）与 `InstrumentReadingsView`——和条带同一份读数控件（额度、缓存寿命、「用量」chip + 用量弹层、上下文量规），每个子代理用自己的 `SessionInstrumentsViewModel`（事件按 `AgentId` 路由，额度按它自己模型的提供商账号读、成本按它自己的模型定价、轮数与耗时读子会话自己的 `turn_metrics`；量规在子代理处只读，压缩走自动策略）；底部状态行已删除。任务气泡在活标签里也有（`AgentSubAgentStarted` 时 `AddUserMessage`，与重放一致——Core 本就把任务作为 user 消息落库）。标签与面包屑的名称是可说出的 id（`Worker-3`，种类被净化时退回「种类 · id」；重启恢复的历史行只剩种类），任务文字由悬停 tooltip 承载。轮末统计行带模型名，与主转录一致；子会话同样写 `turn_metrics`，历史标签重放时按与主会话同一条读数路径补齐（旧子会话无行，读「—」）。 标签标题只写可说出的 id、不带前缀符号：运行中的标签图标用蒂芙尼蓝，只读历史标签用次要灰；子 Agent 的最后一轮结束后 1 小时内标签仍停靠（活名单窗口），到点自动收进底部组的「SubAgents 历史 (n)」，手动关标签则立即收进历史。
- 底部组没有停靠标签就自动缩小到 28 px 标题栏（“SubAgents 历史 (n)” 与新建终端工具照常可用），高度还给转录区；**还原按钮任何状态都画在标题栏上且真的生效**——空组展开就显示「暂无停靠的标签」空态，再点缩小折回。会话还有任何子 Agent 活动（活名单非空或历史条目 > 0）时**整块绝不离开布局**：活名单孩子的标签被浮出后（关闭已被活名单禁关规则禁止），组停在标题栏等它的终局把标签停靠回来；只有零标签、零历史、活名单也空时才整块移出布局，再出现时按原比例放回。折叠空组不写回意图，所以下一条标签停靠时该展开的会话照旧展开；输入条的“SubAgents”chip **可见即可点，没有禁用态**——收起写会话意图，展开经外壳走「手开空态」同一条路（`RevealBottomBody`），空组也展开成「暂无停靠的标签」空态；Agent 会话视图同样画 chip（激活时底部组就是它自己的子 Agent 区域，同一套展开/收起接线）；chip 的强调色读的是真实展开态（`IsBottomBodyOpen` → `SubAgentRegionOpen`），不是意图。
- 标签：25 px 高、贴标题栏底边；激活标签上圆角 5 px、两条侧边到底边**向外**拐 5 px 圆角（`ClipToBounds=False` 才能画出），底边压在下方面板分隔线上；可关闭标签预留 16 px 关闭槽 + 6 px 间距，会话标签的 14 px 图标与项目树同一行完全一致（根会话是气泡、Agent 会话是 `comment_mention`、子 Agent 按层级是 `chat_arrow_back_down`/最深一级 `chat_lock`——一级＝挂在根 Agent 下的那一层，判定看父链接是否为 `root`，三者在 own 标签位于前台时都换成实心变体）；不可关闭标签（TODO/评审/规格树）左右内边距对称。标签放不下时右端出现 `…`，列出被裁剪的标签并滚进视口。
- 停靠条与自动隐藏：仅自动隐藏的边栏在窗口边缘显示 32 px 停靠条（竖排标签 12 px SemiBold、3 px 指示条：只有抽屉里正在显示的那一个 panel 是 `BrandActionBrush`，其余是比它浅两档的 `DockIndicatorIdleBrush`；指示条两端与文字两端对齐）；点标签只把**那一个 panel** 浮进抽屉（同为缩小态先还原；再点收起、点另一条换过去；抽屉里的面板不显示缩小按钮）。抽屉宽度按列给：项目/工具组 = 336，预览组 = 它钉住时那一列的宽度，文件面板 = 336，且预览组有停靠标签时把预览列带到文件列左侧（1 px 线，抽屉跟着变宽，在文件抽屉里点文件就能在左边看到预览）。这次宽度只在打开或有列加入/离开时量一次：**拖中间那条线改的是预览列宽**（文件列拿剩下的），抽屉自己不伸缩；预览的“铺满主区”一直在，按了就把抽屉扩到主区边缘、预览铺满那块区域（**在文件列左缘就停住**，预览连同标题右侧的图标按钮不会落到文件树下面；单独开预览抽屉时没有兄弟列）。抽屉贴停靠条内侧弹出、朝主区一侧有 1 px `BorderBrush` 边框、覆盖主区上方，点外部或 Esc 收起；两个自动隐藏边栏在同一侧时并排。
- 浮动窗口：只允许浮出选项卡（任意组）与文件 panel；文件 panel 浮出时预览组随它进同一个窗口、回位一起回。一个对象一个 `FloatingPanelWindow`（默认 900×640，文件 panel 757×420 = 预览列默认宽 + 文件列默认宽 + 1px 线），同视图模型重新套模板；浮出的标签仍在原组集合里（只标记浮动），点停靠或关窗天然回到原槽位；最小化期间不写回几何；窗口整体带 1 px 边框；标题条 28 px 可拖动、双击最大化。文件 panel 窗口里预览列与文件列之间是 **可拖动的 `PanelSplitter(Preview)`**（与钉住时同一个控件、写同一份 `PreviewWidth`），不是一条画上去的边框。
- 预览列宽度只由一个状态驱动（检视区当前是否含预览列），打开/关闭/浮出都走这一处，避免宽度漂移。
- 区域置换：按住 panel 标题栏空白处横向拖，出现三个落点，放下后两区互换，宽度跟着区域走；自动隐藏中的区域不能拖。

## 7.3 布局快照

- 两份快照都用源生成 JSON 存 `forge.db` 的 `ui_state`：
  - `LayoutSnapshot` v5：区域顺序、宽度、自动隐藏状态、底部组高度与是否缩小、各区 panel 高度比例、预览组开关与宽度、浮动窗口（对象 + 几何）、`belowHeights`（可选追加字段，旧版本缺省即平分）。
  - `OpenTabsSnapshot` v2：打开的标签（预览选项卡存绝对路径）。
- 版本不认识、缺 `version` 或解析失败一律回落默认布局，不迁移；未知 id 丢弃；缺失项保持默认位置；浮动窗口在它装的选项卡存在之后才应用，坐标落在所有屏幕之外时移回主窗口所在屏幕；未放置过的浮动窗口不存坐标，恢复时居中。
- 拖动分隔条松手与切换选项卡各触发一次保存；800 ms 防抖写入。退出时最后一次布局在后台保存，UI 线程最多等 3 秒（超时只记日志）。

## 7.4 项目树

- 行高 28 px；扁平 `RangeObservableCollection` + 虚拟化 `ListBox`；展开/折叠按路径/id 记状态，展开状态跨刷新保留。
- 层级：项目（工作区层，Bold）→ **仓库根检出**（第一个子行；标签取真实分支名，游离显示“游离 HEAD”，非仓库不出现）→ 其它 worktree 分组 → 会话行 → 子 Agent 行（可到孙 Agent）；**Agent 会话行与根会话行同级并列**（同一分支行下、排在它的根会话之后，图标 `comment_mention`；一级子 Agent 是 `chat_arrow_back_down`，最深一级是 `chat_lock`）；归档或已移除的会话收进“历史 (n)”（根会话与 Agent 会话都算）；没有会话的 git worktree 也有一行（裸库与锁定的除外），可新建会话、移除工作区。Agent 会话的回复未读时，行与标签打未读点。项目行行尾按钮是 regular `organization_add`（新建工作区分支，16px，坐在 22px 按钮里），分支行行尾是 `chat_add`（新建会话，14px）；子 Agent 行的状态圆点/对勾坐在同一列 22px 槽里，整棵树的右侧标记对齐成一条竖线。
- 整行可点：会话行打开会话；有子项的行展开/折叠；没有子项的项目/worktree 行新建会话；子 Agent 行先把会话带到主区前台、再展开底部组并选中该标签（活的与已结束的都算）；Enter/空格对选中行生效；点在行内按钮只执行按钮。
- 行尾“+”：项目行是分支加号（打开「新建工作区」对话框，regular `organization_add` 16 px）、常规对话/worktree 行是纯加号（新建会话，`chat_add` 14 px），按钮都是 22 px，tooltip 写清是哪一种。**Agent 会话把 worktree 行（含仓库根检出行）的纯加号改为两项菜单**：“新建会话” / “新增 Agent 会话”（后者是二级菜单：白底、比一级菜单宽，每行“种类名 + 不超过 40 字简述”；Worker 首位加粗，其余种类按模板顺序，不能当 Agent 会话的置灰并给原因）；它挂到该 worktree 的活动根会话，没有活动根会话、合并冲突、工作区操作中时置灰并写入 tooltip，常规对话不提供。一个根名下的 Agent 会话不设数量上限。
- 活动会话行：名称块浅强调底色 + 会话气泡换成实心（与标签页同一对 regular/filled）。
- 子树图标：Scout 放大镜、Worker 锤子、Plan 三行、Reviewer 对勾、未知回落会话气泡；状态：排队/运行/失败/已停止/未知是圆点，正常完成是绿色对勾，文案退到 tooltip；运行中带透明度呼吸动画（受“减少动画”闸门控制）。
- 活动会话行浅强调底；底部组当前选中的子 Agent 标签让树里对应行拿同样的 active 底。
- 会话行带自动化闪电标记（tooltip “由自动化任务创建”）；已归档/已移除/目录缺失/worktree prunable/未登记/状态未知的标记见 01.8。
- 历史行（归档或自愈产生的已移除）点行即打开只读标签（标签没有输入区），右键统一为“恢复会话 / 移除会话”（归档行另有“重命名”）：恢复会话先重建缺失的目录再激活，Agent 会话在分支没有活动 root 时恢复后成为该 root（原父会话转成它的 Agent 会话），有活动 root 时挂到那个 root 下；移除会话不可撤销、直接删除会话记录与附属文件，分支与工作区原样保留。

## 7.5 文件面板与预览列

- 两个标签：**全部**（文件索引的文件数）与**已改动**（当前范围的改动文件数），各有中性数量徽标（选中时翻成面板底 + 强调色数字），0 照常画 0；数字同时进辅助功能名字。这一行与 panel 标题栏同高 28 px、底色 `PanelBandBrush`，与底下两行 git 是同一条带。
- 右上角刷新；「已改动」时刷新换成全部折叠/展开。
- 「已改动」下方是自绘范围下拉与基线下拉（语义见 04.2），选中项命令执行后才关闭弹层。
- 面板最下面两行 git（分支行 + 提交目标行，详见 04.4），排在文件列表之后，无仓库时隐藏。
- 切标签时文件树与 git 行属于**工作区**而不是会话：同一 worktree 里换会话（恢复、晋升、根与 Agent 会话之间）不重建文件索引、不重读 git，只有会话作用域的评审/回合跟着换；换到另一个工作区才整块重读。
- 检出区缩到 200 px 时先让位分支名、再让位结果文字，三个动词永不裁剪；出货行先收远程读数，两个药丸保持完整。
- 文件树的一行**整行是命中目标**：点名称、图标、缩进区、名字右侧空白处都执行该行动作（文件夹开/合、文件打开），只有点在行内按钮上时只跑那个按钮（与项目树同一规则）。
- 点文件在检视区靠主区一侧打开**预览组**（文件预览与逐行审阅）；“全部”里单击复用预览选项卡、右键才新建；“已改动”里点文件打开固定的“改动”选项卡并定位到该文件；预览组“铺满主区”按钮盖住整个主区。
- 行内工具栏：20 px 图标切换自动换行；支持选择、复制、撤销/重做、工具栏保存 / Ctrl+S。

## 7.6 检视区面板

### TODO 面板

- 结构：置顶排队输入行（`＋` + 无边框输入框，Enter 添加为**待排散项**，`TodoOrigin.User`）→ 未完成分组（组行 + 缩进步骤，未完成组始终展开、无删除与折叠入口）→ 待排散项 → 完成区（已完成分组收成一行、点整行展开；已完成散项排其后）→ 历史压底。

## 7.7 转录（聊天时间轴）

- 主会话与子 Agent 共用同一组模板，排成一条时间轴：左侧贯穿细竖线，每个事件一个节点图标落在轴上，内容在节点右侧。
- 节点：用户消息、助手回复、工具调用（按工具名分类：读文件/列目录/搜索/编辑/复制/移动/删除/命令/网络/MCP/子 Agent/计划/通用）、转录提示（只有失败时改用错误图标）、被拒绝的审批（警示色）、回合脚注错误（失败且这一轮**一次工具都没跑**时，脚注右侧给「重试」：把原消息与附件经会话自己的回合入口重发一遍；中途已跑过工具、被停止、或已有更晚一轮的都不给，重放会重复副作用或重开用户已经离开的轮）；已经没有轮次抬头行：轮次信息在用户消息的元信息行与轮末行上，所以每一行都是事件、都有节点。
- 状态：运行中（实心 + 强调色 + 脉冲）、失败（危险色）、审批被拒（警示色）、其余空心 + 次要色；节点不抢焦点、不可点击，`AutomationProperties.Name` 是当前语言的可读名称 + 状态词。
- 工具名到节点的映射在纯函数里（逐个内置工具名 + MCP 的 `server__tool` 分隔符 + 未知名回退），可读名称在 `Strings.Timeline.cs`。
- 几何在纯函数 `TimelineLayout`：每行只回答“上方有节点/下方有节点”，轴从第一个节点起、最后一个节点下截止；虚拟化回收容器时最多 3 次后台重试，耗尽后只画节点不画线，由下一次集合变化纠正。
- 轮次信息分两处：用户消息元信息行显示「第 N 轮 · 时刻」，轮末行显示「耗时 · ↑输入 ↓输出 · 工具 N · 平均输出速率 · 模型名」（`AgentTurnCompleted` 是实例累计，行上显示本轮差值；未上报显示“—”；完整字段与重放配对规则见 `src/Forge.App/SPEC.md`「事件路由与渲染」）。
- 工具行折叠时只显示名字、参数摘要与状态：要你点允许的调用在等待期间右侧是一枚**静态时钟**、正文写「等待审批」（它没在跑，也不给停止按钮）；放行后右侧转圈（卡片与独立工具行复用同一枚 `WaitingGlyph`，不用样式动画），返回后当场换成 √（成功）/ ✗（失败）、空输出也算返回；被拒的就地关成 ✗（正文「已拒绝：<工具名>」），不再多一行提醒；展开后显示输出尾部与结果图片缩略图（首次读 `Thumbnail` 才后台解码，长边默认 256 px、可调 64–1024，不重新编码存下的字节）。
- 思考行：`AgentThinkingDelta` 实时渲染成折叠的思考行、流式追加；思考不落库，重放没有思考行。
- **Markdown 增量渲染**：标题、段落、列表与任务项、引用、表格、分隔线、链接、围栏代码块；用户消息按纯文本（不解析 Markdown）。渲染分“已定稿块前缀 + 未定稿区”：定稿边界是围栏代码块之外的最后空行，前缀只追加、永不重排；未定稿区每帧整体重解析，末尾同段/同标题只换 Inlines，同围栏只换 Text，列表与表格就地生长；超过 4096 字的单段落按行收口；`Complete()` 再对全文解析一次并逐块比对，不一致才整篇替换——最终渲染恒等于“对全文做一次块解析”。
- 代码块：顶部语言标签 + 复制按钮，正文等宽、可横向滚动；`Update(text, info)` 就地换文本，流式不重建控件。每段回答文本各有复制按钮（整条纯文本 = 追加过的原文）。
- Mermaid：` ```mermaid ` 代码块在聊天、diff 预览与计划面板本地渲染成图——Mermaider 解析 + 布局 + SVG → 颜色预处理（算 `color-mix`）→ Svg.Skia 解析成 `SKPicture` → 渲染线程矢量回放（不栅格化、不编码 PNG、DPI 自动清晰）。后台线程、限 2 并发、超时默认 2000 ms（500–30000）、缓存 24 条（源码 + 调色板 + 白名单为键，失败不缓存）；不联网：mermaider 元素/属性白名单消毒 + 拒绝任何非 `#` 开头的 `href`/`url(...)`/`@import`；流式未闭合围栏只显示源码，定稿才渲染；图类型白名单是 `agents` 合并页对话块的逗号列表（默认 flowchart/sequence/state/class/er，另有 pie/quadrant/timeline/gitGraph/mindmap/gantt/journey/c4/requirement/kanban/radar/treemap/venn/sankey/xychart/packet/architecture/block/treeview）。失败保留源码并显示渲染器原文（带行号时写“第 N 行”）、重试按钮与“让模型修正”（固定英文消息，交给块所属会话，忙则进草稿；后台标签页的块绝不把消息发进别的会话）。
- 主题跟随：调色板取自界面表面/正文/强调/次要/边框令牌；主题变化与新挂回可视树时按新调色板重渲染（相同则不重渲）。

## 7.9 全局搜索与命令面板

- 一个覆盖层、五个来源：`Ctrl+P` 文件、`Ctrl+Shift+P` 命令、`Ctrl+Shift+F` 工作区文本；同一个手势再按一次关闭（手势属于来源，重复按不清查询）；标题栏放大镜是同一个动作的按钮；来源内还接受首字符前缀 `>` 命令、`#` 内容、`:` 会话、`@` 符号。切换前台会话即关闭。
- 文件来自 `FileIndex`（仓库内 `git ls-files`，否则有界遍历，遵守 `.gitignore` 与构建目录），匹配复用输入框 `@` 弹层的同一排序；内容来自 `GrepEngine`；会话来自会话目录（子会话与已删除会话不入列，归档带徽标、只读打开）；命令是静态表（行里带手势）；符号来自当前编辑器文档的语言服务器（上限 2000 后排序）。
- 刷新模型：每个来源“快照 + 后台刷新”，先用上一次快照立刻出列表，同时发起刷新；每次刷新带代号，换代后到达的答案丢弃；文件快照按工作区缓存；内容搜索 180 ms 去抖、同一时刻只跑一个。UI 线程每敲一键只做一遍快照过滤，默认上限 50 行（10–500）。
- 预览栏：命令与会话由行字段拼出；文件、匹配行、符号最多保留 256 K 字符、首 40 行或命中行 ±12 行、带行号，解码在后台线程，最近一个文件留在缓存里；读不到/空文件/二进制（首块含 NUL）给“没有可预览的内容”。
- 空与失败：列表为空时说清原因（没有会话、没有打开的编辑器文件、没有语言服务器、搜索失败带原因、首份快照还在读），以不可打开的 notice 行呈现。
- 可配置：`preferences.palettePerSourceLimit`（默认 50，10–500）与 `preferences.paletteExcludeDirectories`（目录名，任意层级整段匹配、大小写不敏感；留空只遵循 `.gitignore`）；配了排除目录时向引擎要 4 倍上限再过滤，过滤后仍超上限或引擎截断时状态行注明“只显示前 N 条”。

## 7.10 资源窗口

- 输入条“资源”按钮打开窗口覆盖层，只看**当前会话**；换会话或会话关闭即关窗。
- 四组，按序：**自动化 Agent**（回合外启动的子 Agent，名称可点开其标签页，带耗时、状态与停止按钮）、**MCP 服务器**（带边框表格：状态、工具数、字符、≈token，重连/停止/启动/登录；停止与重连影响所有会话）、**工具占用**（按类别的字符与≈token，带合计）、**使用的提示词**（各来源字符与≈token，带合计；组头右侧是“快照已过期”小片与“重载”按钮，回合运行中或有自动化子 Agent 在跑时重载禁用并说明原因）。
- 没有命令组：命令卡片只能从转录区对应的命令行打开。token 估算为字符数 / 4 向上取整。
- 刷新由事件驱动并合并，行原地对账；没有定时器。窗口关闭即 dispose，关闭后这些成本为 0。

## 7.11 通知

- 唯一入口 `INotifications.NotifyAsync(level, title, body, key?, ct)`：开关关掉什么都不做；`IsBackground` 为真走系统通知，否则在窗口顶部居中弹 Toast。**任何界面功能要说“某件事发生了”都走这个入口**，不许自建 toast、横幅或第三方通知库。
- 四个等级决定等级条颜色与停留时长：`Info` 4 秒、`Success` 4 秒、`Warning` 6 秒、`Error` 8 秒；两行文本（标题说“发生了什么”，正文给“哪一次/为什么”），都进 `Strings.Notifications.cs`。
- Toast：最新在最上、最多 5 条；同 key 合并成一条并计数 `×N`（key 缺省是“等级 + 标题 + 正文”，重复到来重启计时）；到时先 `IsLeaving` 淡出下滑 180 ms 再移除；`IsHitTestVisible=False`，不挡点击；集合与计时只在 UI 线程动，`NotifyAsync` 可从任意线程调用。
- 窗口在最小化或没有 Forge 窗口在前台时才算后台。释放幂等：就地停计时器与字典，只在 UI 线程清空绑定集合。
- 通知权限引导（14f）：`INotificationPermissionGuide`（`NotApplicable`/`Unknown`/`Granted`/`Denied`）；`SendTestAsync` 真发一条测试通知并把状态落成 Granted/Denied；`OpenSettingsAsync` 打开平台页面（Windows `ms-settings:notifications`、macOS 通知偏好），Linux/NotApplicable 返回 false。设置分区 `notification-permission` 提供状态、发送测试、打开系统设置、`notificationPermissionReprompt`（再次提示）。
- 接入点（每条都带稳定去重 key）：回合/发送失败、提供商未配置、检查点失败、子 Agent 失败或停止、附件拒绝、图片拒绝、读文件失败与文件级上限、换模型后附件阻塞、步骤提交被拒、fetch/pull/push 失败、自动评审交接失败、扩展宿主失败、MCP 服务器失败、模型列表拉取失败、`settings.json` 回落默认、启动或数据库初始化失败、项目列表读取失败、移除会话收尾重试失败、终端非零退出、文件保存失败、LSP 应用失败、评审保存失败、审批卡开始等待用户。
- 不接：生命周期对话框里当场可见的失败、上下文压缩、插话/排队回执、折叠与高亮降级、语言/模型切换、TODO 步骤提交成功。

- 动效：`appearance` 分区的“减少动画”（默认关）写入全局闸门，树的运行中行与聊天时间轴运行中节点立即停止脉冲。
- 图标：只来自 Fluent System Icons 24 px 系列、只内化用到的图形，集中 `Resources/Icons.axaml`，只用 `FluentIcon`（内置 `PathIcon` 的零逻辑子类）渲染；尺寸两档——panel 标题栏与面板内工具栏 14 px、行内微标记 12 px；窗口标题行另有一档（15/13/12）。没有自绘图标控件，视图不手写 `d`。

## 7.14 本地化

- 界面语言中文 / English，切换即时生效（`Loc.Instance` + 编译索引器绑定）。
- 每个可见文案在 `Localization/Strings.<功能>.cs` 注册（`Register(key, 中文, English)`），`[ModuleInitializer]` 注册；同 key 两次注册不同文本直接抛异常；缺失 key 返回 `[key]` 且每个 key 只 Warning 一次。
- 格式：句式随语言，数字与时间不随区域——`TextFormat.Number` 千分位一律 `,`，标识符不分组，时间一律 `HH:mm:ss`，耗时写“4.2 秒 / 3 分 05 秒”。
- 存下来以后再显示的文本（启动诊断、提供商状态、通知、轮次脚注）存成 `LocText`，显示时解析；长生命周期所有者订阅 `LanguageChanged` 并向下刷新，逐行逐卡不订阅静态事件。
- 不翻译：模型输出、用户输入、文件内容与路径、插件文案、会话标题（默认标题按创建时语言生成并存库）、开发者才看的异常文本（英文）。
- “跟随系统”由纯函数 `SystemLanguageDetector.Resolve` 决定（**Avalonia `IPlatformSettings.PreferredApplicationLanguage` → 文化名 `zh*` → Windows 注册表 `PreferredUILanguages` → … → `LC_ALL`/`LC_MESSAGES`/`LANG` → 英文**）；平台值为空（X11/macOS 在 invariant 下就是空）时整条链照旧，注册表读取失败当作不存在，无 P/Invoke；系统换首选语言时经 `PreferredApplicationLanguageChanged` 立即生效。
- 防回归要求（测试项目接线后由测试覆盖）：扫描 `src/Forge.App` 的 `.cs`/`.axaml`，`Strings.*.cs` 之外不得有中日韩字符；表完整性（中英齐全、英文无中日韩字符、占位符一致、XAML/C# 用到的键都已注册）。

## 7.15 首启向导与项目创建

- `OnboardingView` 是窗口内覆盖层，三步：界面语言（直接写偏好、当场切换，跳过也生效）、提供商（只显示状态并深链到 `provider` 分区，不重写编辑/测试/保存链）、通知权限（只经冻结接口读状态与打开系统设置）。
- 是否显示由 `ui_state` 的 `onboarding` 行决定（存在即“看过”，不是偏好）：该行不存在且库里没有**仓库项目**时才显示；已有仓库项目的安装视为非首启、静默补一条记录；`ui_state` 读不出来按已看过处理。
- 触发点在窗口、由应用程序开启：只有真窗口能显示覆盖层，自己造窗口的宿主（测试、录制）不置标志，所以它永远不会遮住工作台。
- “添加项目”是一次性选择：已有文件夹 / 克隆仓库 / 新建项目；三条分支共用同一个注册尾（`IProjectRegistry.AddAsync` + 刷新缓存 + 刷新两棵树），注册抛错时发错误通知而不是让异常逃进调度器。
- 克隆显示进度并可停止，取消或失败不留半截目录；窗口在克隆途中被关掉等同取消；完成通知在运行状态落定之后才发；超时失败呈现 `GitException.Message`（唯一说得清原因的一句）而不是一屏进度重绘的 stderr。

## 7.16 性能与布局纪律

- UI 线程只做渲染与输入；LSP、着色、Git、文件扫描一律后台线程，结果经不可变快照回到 UI。
- 树、列表、Diff 虚拟化；Diff 与编辑器增量渲染，不整体重绘；流式输出按渲染帧批量合并（每帧最多一次 UI 更新）。
- 工作台区域与面板必须按最终分配的宽高测量与排列：滚动视口不得沿用整窗口高度，分割/抽屉/最大化/缩放后 `ScrollViewer` 与虚拟化 `ListBox` 滚到末端要能完整看到最后一行——不用底部留白或滚动补偿掩盖布局错误；仍可见的面板不得在每次排列前临时排到零尺寸。
- 零分配细节：`NotifyingObject.SetAndNotify`、属性名缓存 `PropertyChangedEventArgs`、拖动路径不分配、`RegionWidthSolver` 纯函数、跟踪图标几何缓存。
